## Tecnologías utilizadas

- HTML5 semántico
- CSS3
- Google Fonts
- CSS Grid
- Flexbox
- Responsive Design
- Transiciones y animaciones CSS
- SVG para la ilustración decorativa

## Decisiones de diseño

Elegí una estética cálida y minimalista, con tonos neutros y marrones para relacionar el diseño con el dibujo y la creatividad.

La tipografía `Playfair Display` se utiliza principalmente para títulos y `DM Sans` para el texto general, buscando contraste y buena legibilidad.

Utilicé CSS Grid para organizar las secciones principales y las tarjetas de habilidades. También incorporé Flexbox en la navegación y en algunos grupos de elementos.

La animación flotante del bloque principal y las transiciones de las tarjetas y botones aportan interactividad sin sobrecargar la página.

El diseño incluye media queries para adaptarse a celulares, tablets y pantallas grandes.
